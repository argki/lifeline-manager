# Lifeline Domain & Feature Development

[要件定義書](../../../docs/requirements.md) に基づき、コア機能と UI を実装・検証するための手順。

## 1. ドメインモデル設計指針

1. **階層構造**: `Site (拠点)` → `UtilityConfig (種別設定: 水道 / 電力 / ガス)` → `YearlyRecord (年次データ)` → `MonthlyEntry (使用量・金額)`。
   - 「灯油」は対象外。
   - 拠点の追加・名称変更・削除（誤操作防止確認付き）に対応し、拠点ごとに種別メタデータ（事業者名、単位、小数点桁数、対象月配列、請求月補足）を独立して持たせる。
2. **年・日付の扱い**:
   - 内部キーは西暦（例: `2026`）で管理し、表示時に和暦（`H29`, `R8` 等）へ変換する純粋関数を用意する。
3. **集計ルール**:
   - `合計`: 入力済み月の値を合算（小数点誤差に注意し丸め処理を明示）。
   - `平均`: **未入力（`null` / `undefined`）を分母から除外**して算出。実績 0 件の場合は `null` を返し、UI で `-` 表示とする（`#DIV/0!` を出さない）。

## 2. UI / 可視化指針

1. **入力テーブル**:
   - 年（行）× 対象月（列）のマトリクス表示。1 年あたり上段「使用量」・下段「金額」の 2 段構成を維持する。
   - セルの直接編集・キーボード移動に対応し、新規年追加ボタンで将来年を手動メンテなしで追加できるようにする。
2. **リアルタイムグラフ**:
   - 「グラフに反映」ボタンは置かず、セル編集と同時に状態更新して折れ線グラフへ即時反映する。
   - 平成グループ / 令和グループ表示、および任意年のチェックボックス ON/OFF フィルタを提供する。
   - 初期リリース（Phase 1）は使用量グラフを実装し、金額グラフ切り替え（Phase 2）を追加しやすいコンポーネント設計にする。

## 3. データ移行・バックアップ

- 全拠点一括および拠点単位での JSON / CSV エクスポート・インポートを実装する。
- 既存 Excel 書き出し CSV 形式に対して以下に対応するパーサを実装する：
  - 取り込み先の拠点を指定できること。
  - 月ヘッダ行（`1月`〜`12月` または `1月,3月,...`）を固定行番号ではなく動的に検出し、月列の範囲のみを読み取る（`計`・`平均`・右端のメモ列は無視）。
  - 1行目の種別名（`プロパンガス`、`東京電力`、`水道使用量`）および 2列目の項目名（`㎥`, `ｋWh`, `使用量㎡`, `円`, `金額`）を全角/半角ゆらぎを含めて判別する。
  - 数値の前後空白・カンマ区切りを除去してパースし、和暦空欄行や `#DIV/0!`・`-` を無視する。
  - 平成17年（`H17`）など長期の和暦変換（`H31` / `R1` いずれも `2019` 対応）および使用量・金額の片側のみ入力された行を正しく扱う。

## 4. 検証手順

1. ドメインロジック（和暦変換、隔月/毎月集計、空欄除外平均、インポートパーサ）に対して単体テストを作成し、コンテナ内で全テストがパスすることを確認する。
2. 表セル編集時に集計値およびグラフ系列データが即座に更新されることを結合テストまたはコンポーネントテストで確認する。
