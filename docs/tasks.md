# ライフライン使用量・料金管理アプリ 開発タスクリスト

[要件定義書](./requirements.md) に基づく実装タスク一覧。

## Step 1: 設計・コンテナ基盤・品質環境構築
- [x] **詳細技術設計の確定**
  - フロントエンド（TypeScript + React + Vite + グラフライブラリ）およびローカル API（Node.js 等）の構成確定
  - 永続化フォーマット（JSON ファイルまたは SQLite）の確定
  - データモデル設計（`Site` → `UtilityConfig`［水道/電力/ガス］ → `YearlyRecord` → `MonthlyEntry`）
- [x] **Docker / Docker Compose 環境構築**
  - `Dockerfile` および `compose.yaml` 作成（ホスト OS 非汚染）
  - `127.0.0.1` 限定ポートバインド設定
  - ホスト側ローカルデータディレクトリ（例：`./data`）のボリュームマウント設定と `.gitignore` 設定
- [x] **品質管理・依存関係最新化の整備**
  - `pnpm` 導入とロックファイル管理
  - TypeScript (`tsc`)、Linter / Formatter（ESLint / Prettier 等）、テストランナー（Vitest）設定
  - Renovate または Dependabot 設定ファイル追加（npm パッケージ・Docker イメージ自動更新）

## Step 2: ドメインロジック実装・単体テスト
- [x] **和暦・西暦変換モジュール**
  - 内部西暦 ⇔ 和暦表示変換（`H17`〜`H31` / `R1` / `R2`〜 対応）
  - 単体テスト作成
- [x] **ライフライン種別メタデータ・集計ロジック**
  - 水道（隔月 1,3,5,7,9,11月 / `㎥`）、電力（毎月 1〜12月 / `kWh` / 請求月補足）、ガス（毎月 1〜12月 / `㎥`）の定義（「灯油」除外）
  - 年次「合計」「平均」算出ロジック（未入力月を分母から除外、0 件時は `null` / `-` 表示で `#DIV/0!` 排除）
  - 単体テスト作成
- [x] **データ移行（CSV インポート / エクスポート）パーサ**
  - 既存 Excel 書き出し CSV 形式に対応した CSV パーサ実装
    - 月ヘッダ行の動的検出、`計` / `平均` / 表外メモ列の除外
    - 全角文字（`ｋWh` 等）・空白・カンマ区切り・和暦空欄行・`#DIV/0!`・`-` の正規化/除外
    - 使用量・金額の片側欠損データの許容
  - 全拠点一括および拠点単位の JSON / CSV エクスポート・インポートロジック実装
  - CSV パーサの単体テスト作成

## Step 3: ローカル API・永続化層実装
- [x] **データ永続化ストア**
  - コンテナ内のマウント先（`/app/data` 等）への安全な読み書き処理
- [x] **ローカル API エンドポイント実装**
  - ヘルスチェック API（起動スクリプト待機用）
  - 拠点 CRUD API（一覧・追加・名称変更・削除）

  - CSV / JSON インポート・エクスポート API（拠点指定取り込み対応）

## Step 4: フロントエンド UI 実装
- [x] **拠点・種別ナビゲーション**
  - 拠点切り替え UI、拠点追加・名称変更・削除（確認ダイアログ付き）機能
  - 種別切り替えタブ（水道・電力・ガス）と単位・請求月補足ラベル表示
- [x] **表形式入力・自動集計 UI**
  - 年（行）× 対象月（列）のマトリクス表（上段：使用量、下段：金額）
  - セル直接入力・キーボード操作・バリデーション
  - 合計・平均のリアルタイム表示（0 件時 `-` 表示）、「年を追加」機能
- [x] **リアルタイム折れ線グラフ**
  - 入力・編集と同時（ボタン操作なし）のグラフ即時反映
  - 平成／令和グループ表示、および比較対象年のチェックボックス ON/OFF フィルタ
  - マウスホバー時の数値ツールチップ表示
- [x] **データ移行・バックアップ画面**
  - 取り込み先拠点を指定できる CSV インポート UI
  - 全拠点／拠点単位のエクスポート・インポート UI

## Step 5: ダブルクリック起動スクリプト・結合検証
- [x] **OS 別ワンステップ起動・停止スクリプト作成**

  - macOS 用：`start.command` / `stop.command`（実行権限付与・同様の自動起動/停止フロー）
- [ ] **総合検証**
  - コンテナ内での型チェック・Lint・全単体テスト・本番ビルドの通過確認
  - 実データ CSV の取り込みと集計値・グラフ一致確認
  - コンテナ再作成後のデータ永続化確認、および `127.0.0.1` 限定公開確認
  - Windows / macOS 双方でのダブルクリック起動〜終了の動作確認
